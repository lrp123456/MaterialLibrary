### ⚠️ 一个必须知道的事实

**OpenCut 的 wasm 原本只内置了一个 shader：`gaussian-blur`**
（`editor/rust/crates/effects/src/pipeline.rs`）。

**2026-10-20 12:05 已解除该限制**：新增 3 个 shader 并重编了 `opencut-wasm`。

| shader id | 用途 | 参数槽 |
|---|---|---|
| `glow` | 亮部提取 + 环形采样 + 加性合成 | scalars.x=阈值 / y=强度 / z=半径 |
| `sharpen` | 4 邻域反锐化掩模 | scalars.x=强度 / y=半径 |
| `skin-smooth` | 双边滤波近似（保边平滑），全局磨皮 | scalars.x=强度 / y=半径 |

配套改造：
- `pack_effect_uniforms` 从"只认 u_sigma/u_step/u_direction"放宽为支持 `u_scalar0..3`，旧参数仍兼容；
- `shader_defs` 数组化，新增 shader 从"复制 60 行管线"变成"加一行"；
- 构建：`wasm-pack 0.15.0` + `wasm32-unknown-unknown`，产物已替换进 `node_modules/opencut-wasm`（原件备份为 `opencut-wasm.bak-0.2.10`）；
- **WGSL 离线校验**：4 个 shader 全部通过 naga parse + validate（0 失败），不依赖浏览器。

> 仍然做不到的：**人脸级美颜**。`skin-smooth` 是全局保边平滑，不做人脸检测/瘦脸。
> 那需要人脸关键点模型，属于服务端 AI 任务（`face_reshape`），见第 5 节 M4。

## 7. 环境坑（本次新增，已在项目记忆里）

| 坑 | 现象 | 绕法 |
|---|---|---|
| npm 批量删除被拦 | `SAFE_DELETE_BULK_CONFIRM_REQUIRED` | 换独立 `--cache` 目录；依赖缺失时用 `npm pack` + 解包绕过树重建 |
| Next 清理 `.next` 被拦 | 构建启动即失败 | `distDir` 指向全新目录（`NEXT_DIST_DIR`） |
| Git Bash 路径转换 | `NEXT_PUBLIC_BASE_PATH=/editor` 被转成 `C:/.../editor` | 写进 `.env.local`，不通过命令行传 |
| `better-sqlite3` 是 Linux 模块 | Windows 侧无法 `require` | 测试用 Node 24 内置 `node:sqlite` |
