## 1. 左栏 7 栏

| key | 中文 | 二级 | 职责边界 |
|---|---|---|---|
| `media` | 素材 | 图片 / 视频 / 贴纸 / 云端 | 一切可作为画面元素拖入的对象 |
| `audio` | 音频 | 音乐 / 音效 / 录音 / 提取 | 只能落音频轨 |
| `text` | 文本 | 标题 / 花字 / 字幕 / 智能字幕 | 前三者"放一个"，后者"生成一批" |
| `transition` | 转场 | 全部 / 收藏 | 拖到剪辑点 |
| `effects` | 效果 | 特效 / 滤镜 / 调节 | 拖到片段 |
| `plugins` | 插件 | AI 工具 / 已装资源包 | 声明式能力入口 |
| `settings` | 工程 | 画布 / 帧率 / 背景 | 不属于内容 |

**迁移映射**（旧 → 新）：
`media` + `library` + `stickers` → `media`；`sounds` → `audio`；`text` + `captions` → `text`；
`effects` → `effects`；`ai` → `plugins`；`settings` → `settings`；新增 `transition`。

**要求**：面板内二级用顶部 chip，不新开一级栏；每个二级保留独立空态文案；
`assets-panel-store` 的 `activeTab` 加持久化迁移（旧值 `library`/`stickers`/`captions`/`ai` 映射到新 tab）。

## 2. 转场（引擎级）

### 2.1 数据模型

```
VideoElement.transitionOut?: {
  type: string;        // 资源包 id，如 com.mls.transition.dissolve
  duration: MediaTime; // 秒
  params: ParamValues;
}
```

- 语义：绑定在**左侧片段**的尾部。剪辑点 `C = A.end`，渲染窗口 `[C - d, C]`。
- **应用转场的精确几何**（v1.1 修订）：
  - A：**完全不动**，只写入 `transitionOut`
  - B：`startTime -= d`（`trimStart` / `duration` 都不动）
  - 同轨后续元素整体前移 `d`（波纹），总时长减 `d`
- **v1 的"两边各让 d/2"已废弃**：A 扩 d/2 + B 提前 d/2 时 B 的结尾位置不变，总时长只减 d/2；
  再让后续元素前移 d 会把 B 尾部压住 d。**"各让一半"与"总时长减 d"在几何上不可同时成立。**
  现模型牺牲对称性，换来 **两边都不吃素材余量、不会冻结**。
- **删除转场**：B 与后续元素整体后移 `d`，A 不动。

### 2.2 渲染通道

`FrameItemDescriptor` 增加一种（Rust `compositor/src/compositor.rs` + bridge）：

```rust
Transition { from: LayerDescriptor, to: LayerDescriptor, progress: f32, mode: u32, scalars: [f32;4], direction: [f32;2] }
```

合成器对 `from`/`to` 各调一次 `render_layer` 得到两张纹理，再用 `transition.wgsl` 混合后
按普通 Layer 贴回 scene。**不经过 effects 管线**（effects 是单输入，扩展它会污染 blur 等既有 shader）。

`transition.wgsl` uniform 布局（16 字节对齐）：

```
resolution: vec2f   // 0
progress:   f32     // 8
mode:       u32     // 12
scalars:    vec4f   // 16  (x=softness, y=amount, z/w 预留)
direction:  vec2f   // 32  (推移/擦除方向)
_pad:       vec2f   // 40
```

### 2.3 首批 12 个（mode 常量）

| mode | 名称 | 依赖 | 参数 |
|---|---|---|---|
| 0 | 叠化 | 纯混合 | softness |
| 1 | 黑场过渡 | 混合 + 亮度 | 无 |
| 2 | 白场过渡 | 混合 + 亮度 | 无 |
| 3 | 左推 | 位移采样 | 方向 |
| 4 | 上推 | 位移采样 | 方向 |
| 5 | 缩放推近 | 缩放采样 | amount |
| 6 | 旋转 | 旋转采样 | amount |
| 7 | 模糊过渡 | 二次采样 + 高斯 | softness |
| 8 | 线性擦除 | 阈值 + 羽化 | 方向/softness |
| 9 | 百叶窗 | 条纹阈值 | amount/softness |
| 10 | 置换故障 | 噪声扰动 UV | amount |
| 11 | 翻页 | 透视 UV + 高光 | softness |

全部走资源包（`type:"transition"`，schema 已预留 `transition.defaultDuration`），
`data/clip-packs/com.mls.transition.*` 各一个包，`manifest.render.passes[0].shader = "transition"`，
`uniforms.mode` 由包内参数注入（需在 loader 增加 `mode` 透传）。

## 3. Shader 家族（`rust/crates/effects`）

新增 3 个 `.wgsl`，走现有 `shader_defs` 数组注册（一行一个），uniform 用 `u_scalar0..3`。

| shader id | 用途 | scalars 约定 |
|---|---|---|
| `grade` | 亮度/对比度/饱和度/色温/色调/反相/褪色 | 0=亮度 1=对比度 2=饱和度 3=色温（色调与反相走 mode 位）|
| `warp` | 波形/湍流/旋转/球化/镜像/放大/网格 | 0=amount 1=scale 2=phase 3=mode |
| `channel` | 通道混合/曲线近似/着色 | 0=r 1=g 2=b 3=mode |

> `warp` 的 mode 用整数编码（0=wave 1=turbulent 2=twirl 3=spherize 4=mirror 5=magnify 6=grid），
> 与 Concat 的 18 个滤镜不重合，只为覆盖逆向出的效果构成。

**注册后必须同步三处**：`pipeline.rs` 的 `shader_defs` / `builtin_shader_ids()`、
`src/clip-packs.js` 与 `apps/web/src/services/clip-packs/index.ts` 的 `BUILTIN_SHADERS`。

**构建**：`wasm-pack build rust/wasm --target bundler --out-dir pkg --release`，
产物替换 `apps/web/node_modules/opencut-wasm/`（原件备份 `opencut-wasm.bak-0.2.10` 保留）。
先过 `C:\Users\lrp\rea-install\tools\wgsl-check` 的 naga parse+validate。

## 4. 素材层

- 单一列表源：`GET /editor-api/clip-assets`（已存在）+ 本地 IndexedDB 媒体，前端合并去重（按 fid/哈希）。
- 每项带 `origin: "local" | "cloud"` 角标；cloud 项显示「未下载」态。
- 拖拽 cloud 项：先落占位元素（`pendingFid`），并发起 `/api/assets/:fid/download`，完成后替换 `mediaId`；
  失败则移除占位并 toast。
- 删除保护沿用现有 409（`src/assets-delete.js`），不新增逻辑。

## 5. 插件（声明式）

`pack-manifest.schema.json` 的 `type` 增加 `operation`：

```json
{
  "type": "operation",
  "operation": {
    "input": ["video"],
    "output": "cuts",
    "runner": "scene-split",
    "params": [{ "key": "threshold", "type": "number", "default": 27 }]
  }
}
```

- 前端插件：`renderer` 为本地 shader 组合，即时生效（如"自动调色"）。
- 服务端插件：走 `clip_ai_jobs`，`runner` 对应 `data/clip-ai-runners/<runner>.js`。
- **不引入任何 JS 执行**：清单只声明能力，执行体固定在服务端 runner 目录。

## 6. 服务端 AI 通道

| 接口 | 用途 | 说明 |
|---|---|---|
| `POST /editor-api/ai/tts` | 文本转语音 | 转发 `runVoiceJob`；入参 `{text, lang, voiceId \| refFid, emoFid?}` |
| `POST /editor-api/ai/scene-split` | 镜头检测 | runner `scene-split`，产出 `cuts: number[]`（秒）|
| `POST /editor-api/ai/vocal-separate` | 人声分离 | runner `vocal-separate`，产出人声轨素材 |

音色库：`data/voices/<id>/{ref.wav, meta.json}`，`GET /editor-api/ai/voices` 列表。
**内置音色只用自录或 CC-BY 语料，附 `license` 与 `source`；不用影视片段。**

## 7. 工程文件导出（`.mlsclip`）

zip 结构：

```
project.json      # 工程全量（含 storage 序列化结果）
assets.json       # 素材清单：fid / 文件名 / 大小 / sha256 / 是否内嵌
media/            # 可选，内嵌媒体（默认不嵌，仅清单）
manifest.json     # 版本、导出版本、创建时间
```

用途：换机打开、备份、交给桌面版做 4K120 高质量导出。
**导入**：校验 manifest 版本 → 逐项比对 sha256 → 缺失项列清单让用户补齐。
