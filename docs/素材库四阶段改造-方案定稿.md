## 一、授权与可见性治理（P1 ✅ 已完成）

### 背景

旧严格幽灵机制（`reconcileGhosts` + `isGhostFile`）在快照与资产零交集时会把 ~4,986 图片全部隐藏。已拍板**整体替换**为宽松授权治理。

### 最终语义（全部拍板项）

1. **授权 JSON = 相册同步快照**（MaterialViewer SyncTab / AlbumSync → `POST /api/snapshot`，契约不变），匹配键 `file_name + size`（与快照 itemKey 同构）。
2. **宽松治理**：仅 `source='quark'` 且被快照匹配过的资产受管辖；**从未匹配 = unmanaged 永久可见**；upload 直传资产豁免。
3. **fail-open**：无任何设备推送过快照时全量可见（沿用 `getSnapshotKeySet` 返回 null 语义）。
4. **时钟 = `discovered_at`**（首次入库）：<72h 为 live（随 JSON 增删）；满 72h 冻结——**锁定当时可见性**：可见→frozen 永久可见，已撤销→frozen_revoked 永久隐藏，JSON 后续变化对二者均无效。
5. **撤销可逆**：<72h 从快照消失 → revoked 隐藏（数据/衍生图/标签全保留），快照重新出现即复活为 live。
6. **祖父条款**：首次匹配时已 ≥72h → 立即 frozen（全部存量资产走此路径，安全）。
7. **admin 逃生口**：`POST /api/auth/reset {fid}` → auth_state 置回 unmanaged，下轮治理重判。

### auth_state 状态机

| 现态 | 条件 | 次态 |
|---|---|---|
| NULL/unmanaged | 命中快照 且 age<72h | live（auth_matched_at=now） |
| NULL/unmanaged | 命中快照 且 age≥72h | frozen |
| live | 仍在快照 | live |
| live | 离开快照 且 age<72h | revoked（auth_revoked_at=now） |
| live/revoked | age≥72h | frozen / frozen_revoked（锁定） |
| revoked | 重新命中快照 | live（复活） |
| frozen/frozen_revoked | 任何 | 不变（JSON 免疫） |

**可见性谓词**（读者端统一追加）：
```sql
(a.auth_state IS NULL OR a.auth_state IN ('live','frozen'))
```

## 二、统一处理网关 + 图片/视频处理（P2，待实施）

### 网关契约（用户后台按此实现；服务端先按契约写适配器 + mock 验证）

## 四、色彩系统重构（P3，待实施）

### 三层模型（已拍板，替换 4bit 量化 + 18 色名表简陋管线）

**1. 像素层 — 抗干扰提取**（新建 `src/colors.js`）：
sharp 降采样长边 160px → 灰世界白平衡 → 中心加权（中心 1.0 → 边缘 0.3）→ HSV 过滤（S<0.12 入中性池；V>0.95 过曝剔除；V<0.08 死黑剔除）→ Lab/OKLab k-means++ K=7 → ΔE2000<4 合并 → 权重<2.5% 丢弃 → 显著性打分 `0.4×面积 + 0.3×饱和 + 0.2×中心 + 0.1×对比`。

**2. 角色层 — 60-30-10 规则初值**：
- 中性池永不竞争 main（整图中性占比>85% 除外，此时 main=中性最大簇+打黑白灰标签）
- 彩色池最大簇≥15% → main；全碎 → main=加权平均材质色+标记中性基调
- secondary=彩色池第 2/3 大且与 main ΔE>10
- accent=权重 3–15% 中显著性最高（或与 main 色相差 120–180°），取 1–2 个，**允许 null**

**3. 语义层 — VLM 复核 + 归一派生**：
- **VLM 复核（零额外成本）**：tag 节点同一调用的 color_review 字段复核角色（主体/背景/点缀），与规则初值冲突时以 VLM 判断纠偏（**hex 仍纯像素**）
- **基础色 12 归一**：确定性 HSL 规则表 `basicColorOfHex()`，写入 asset_colors.basic_color：

| 基础色 | 规则 |
|---|---|
| 白/灰/黑 | S<0.12 中性：白 L≥0.80 / 灰 0.20–0.80 / 黑 <0.20 |
| 红 | H≥345 或 <15（非粉） |
| 粉 | H 315–345 且 L>0.6（否则归红） |
| 橙 | H 15–40 且 L≥0.35 |
| 棕 | H 15–50 且 L<0.35（含深黄棕） |
| 黄 | H 40–65（含米/杏/奶油低饱和暖亮色） |
| 绿 | H 65–170 |
| 青 | H 170–200 |
| 蓝 | H 200–255 |
| 紫 | H 255–315 |
| 金属修正 | 金→黄、黄铜→橙、钢银→灰 |

- **色系风格 8 派生**（asset_tags dimension='color_style'，source='derived'，多标签）：黑白灰极简（中性>85%）/ 原木日系（暖棕黄簇 H25–45 权重最高）/ 大地侘寂（H20–60 中低饱和低明度）/ 莫兰迪低饱和（彩色簇全 S<0.4）/ 奶油马卡龙（主色 L>0.75 低饱和偏暖）/ 暖色调 / 冷色调 / 高饱和撞色（≥2 簇 S>0.7 且 ΔH>120°）

### 展示与筛选
