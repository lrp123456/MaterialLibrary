## 2. 核心端口与网络拓扑

| 端口 | 服务名称 | 进程入口 | 作用与对外协议 |
| :--- | :--- | :--- | :--- |
| **`30001`** | **Core API Server** | `src/server.js` | WSL 内部业务中枢，处理所有 REST API、WebSocket（`/api/push`）、语音流（`/api/asr/stream`） |
| **`30002`** | **Desktop Web Gateway** | `web-pro/server.cjs` | 桌面端统一服务入口。托管 `web-pro/dist` 静态资源，同时透明反向代理 `/api/*` 到 30001 |
| **`3010`**  | **Editor Sub-app** | `editor/apps/web` | Next.js 剪辑子应用（basePath=`/editor`），由 30002 网关统一反向代理提供给主应用嵌入 |

## 3. 基础素材库（Base Library）业务架构

基础素材服务于空间设计、材质替换、微调与全案风格编译，数据结构分层如下：

### 3.1 一级四大板块
1. **材质 (`material`)**：所有空间基础界面材料；
2. **做法 (`design`)**：吊顶造型、墙面造型、门窗构件等节点构造；
3. **选品 (`product`)**：独立单体家具、灯具、地毯、成品软装；
4. **风格方案 (`scheme`)**：由整套色彩与材质编译组合的整案风格模板。

### 3.2 材质五大使用面与材料细分
- **墙面 (`wall`)**：
  - `latex`（乳胶漆）：覆盖立邦官方百搭色（898款带真实空间实景图，8大主色精准分类）；
  - `microcement`（微水泥）：艺术漆微水泥；
  - `wallpaper`（墙纸）；
  - `wallcloth`（墙布）；
  - `wood_veneer`（木饰面，仅收上墙饰面板）。
- **顶面 (`ceiling`)**：
  - `latex`（乳胶漆）：共用墙面立邦色号；
  - `microcement`（微水泥）。
- **地面 (`floor`)**：
  - `tile`（瓷砖）：覆盖冠珠瓷砖（884款带单片平面材质图+铺贴实景图，亮光/柔光/哑光，石纹/木纹/拼花/纯色）；
  - `wood_flooring`（木地板）：实木与复合地板。
- **软装 (`soft`)**：
  - `fabric`（织物）：棉麻、丝绒、科技布；
  - `leather`（皮革）：真皮、马鞍皮、超纤皮。
- **全屋定制 (`millwork`)**：
  - `board`（板材）：柜体板、柜门板；
  - `door_color`（门的材质和颜色）；
  - `door_casing`（门套）；
  - `baseboard`（踢脚线）；
  - `countertop`（台面和窗台石）：由大板瓷砖与岩板挂载支撑。

### 3.3 数据存储与挂载关系 (`ba_item_mounts`)
- 数据库表结构：
  - `ba_items`：存储素材实体核心元数据（ID、名称、提示词、色值、光泽、纹理、平面图 `preview_rel`、实景搭配图 `scene_rel`、图组 JSON `images_json`）；
  - `ba_item_mounts`：联合主键 `(item_id, mount)`，实现一条记录在多个空间面（如 `wall` + `ceiling` 或 `floor` + `millwork`）共用挂载，无冗余数据。

## 4. 常用运维与构建工作流指令

### 4.1 服务启动与重启
```bash
# 进入 WSL 终端并在代码工作区执行：
cd /mnt/c/Users/lrp/DevEcoStudioProjects/MaterialLibraryServer
./start.sh restart
```

### 4.2 前端构建
```powershell
# 在 Windows 终端执行：
npm --prefix web-pro run build
```

### 4.3 基础素材全量重构与生产库注入
```bash
# 在 WSL 或 Windows 运行：
node scripts/build-base-library.js
```

### 4.4 自动化测试回归
```bash
npm test
```
