# Stitch 提示词 · 素材库

桌面端，宽 1440。一次只贴一张画板分隔线里的正文。三张都要嵌同一条顶栏，不得重画顶栏。不要左栏。不要生成空间创作、剪辑、设置。

顶栏准绳：项目 `7051111932614979142`，屏幕 `150266a7b49244798826ab7ea1acd652`。悬浮亚克力浮岛。品牌「灵感空间 PRO」。板块是空间创作、素材库、剪辑、设置，图标加文字。本包当前项是素材库。下拉默认关闭。下拉只有：图片、视频、音频、基础素材、剪辑工程、回收站。这六项禁止出现在内容区。

亚克力只用于顶栏。中间栏、抽屉、卡片、网格是扁平深色表面。不要新拟态，不要全页毛玻璃，不要写十六进制，不要发明新色板。语言简体中文。不要 emoji，不要人脸和水印。

页面在顶栏下分成两栏。中间栏放内部板块和筛选。右侧放素材。常用筛选在中间栏。高级筛选是从中间栏打开的抽屉，默认这一套规则；只有画板一把抽屉画成打开。

未画成画板、但必须遵守的同构页面：

- 视频。内部板块：空间漫游、单品展示、细节特写、商业短片、人像动态。常用筛选：时间、关键字、货架（原素材、精修素材、成品素材）、来源（手机实拍、AI 创作）、画幅（16:9 横图、9:16 竖图）。无高级抽屉。
- 音频。内部板块：氛围背景乐、环境音效。常用筛选：时间、关键字、货架。高级抽屉：情绪（轻松、抒情、欢快、安静、史诗、紧张、温暖、复古）。
- 天花。货架：乳胶漆平顶、微水泥一体顶、木质天花、石膏线与灯盘、金属集成吊顶、发光软膜。乳胶漆平顶的常用筛选：关键字、品牌（立邦、多乐士）、色系（米白珍珠、暖调米咖、原麻灰米、现代冷灰、复古草绿、中性象牙、纯净雪域）。高级抽屉：仅看置顶色卡。其余货架只有关键字。
- 墙面。货架：乳胶漆平涂、微水泥与灰泥、木饰面与格栅、壁纸壁布与软硬包、石材与岩板、瓷砖与手工砖、特色装饰板。乳胶漆平涂的筛选与天花乳胶漆相同。其余货架只有关键字。
- 全屋定制。货架：肤感膜门板、双饰面板、烤漆门板、框门与玻璃门、台面。筛选：关键字。
- 活动家具。货架分段：换表面（木作面、石材面、真皮、织物、金属、玻璃），换整件（沙发、几桌、椅凳、床与柜）。筛选：关键字。
- 软装。换表面：窗帘、抱枕与盖毯、块毯。换整件：摆件与花器、画与画框。筛选：关键字。
- 卫浴厨电五金。货架：洁具、浴缸、水槽与龙头、花洒与门窗五金。筛选：关键字。
- 剪辑工程。工程引用的筛选：时间、关键字、剪辑项目、媒体类型（全部、图片、视频、音频）。导出成片的筛选：时间、关键字。
- 回收站。内部板块：AI 闸门拦截、人工删除。共用筛选：时间、关键字。
- 图片下未画出的页。空间人像常用筛选：时间、关键字、货架、景别（全身、半身、特写）。高级抽屉：性别（女、男、儿童、中性），人物风格（温婉、大方、干练、知性、甜美、国风、酷飒、职场、居家休闲）。服装服饰常用筛选：时间、关键字、货架、季节（春夏、秋冬、通季）。高级抽屉：服装品类（上衣、裤装、裙装、外套、套装、鞋包），穿搭风格（通勤、休闲、运动、礼服、国潮、法式、极简、甜酷、街头潮牌）。单品家具常用筛选：时间、关键字、货架、家具大类（坐具、案几台桌、收纳柜架、卧具寝具）。高级抽屉：单品（休闲椅/扶手椅、餐椅、吧椅、单人沙发、三人/组合沙发、长凳/换鞋凳/脚踏、茶几、餐桌、边几/角几、书桌/工作台、电视柜、餐边柜、斗柜、书架/展示柜、衣柜、床/床架、床头柜），表面工艺（哑光烤漆、高光烤漆、做旧复古、拉丝金属、阳极氧化、电镀抛光、烟熏碳化、木蜡油天然、粗粝肌理）。单品里不要出现吊灯、壁灯、台灯、落地灯。
