# 空间创作最终提示词

已作废。空间创作的准绳改为 `stitch-空间创作.md`。顶栏的准绳改为 `stitch-顶栏.md`。不要再把本文件交给 Stitch。

把分隔线之内的正文整段交给 Stitch。桌面端，宽 1440。只生成空间创作这一页的几块画板。不要改成另一套品牌。

---

设计桌面 Web 应用「灵感空间」里的「空间创作」页。使用者是室内设计师，对着已有照片写下一张图。语言简体中文。字体：界面 Plus Jakarta Sans，中文回退苹方；图号和文件名用 JetBrains Mono。圆角 12。1px 实线边框。密度高，留白少而整齐。动效只允许 150 到 200ms 的悬停。不要渐变背景，不要玻璃拟态，不要大阴影，不要 emoji，不要营销标题，不要金色，不要衬线大标题。

色值固定，沿用现有暗色工作台：

- 页面底 #0A0E17
- 栏、抽屉、输入区 #131A29
- 卡片 #182236
- 悬停 #212E47
- 输入槽 #0D121D
- 边框 #27354D
- 主文字 #F8FAFC
- 次文字 #94A3B8
- 弱文字 #64748B
- 主按钮和选中描边 #6366F1，悬停 #4F46E5，按钮字 #FFFFFF
- 图号芯片字 #06B6D4，芯片底为该色 15% 透明
- 成功 #10B981
- 危险 #F43F5E

照片是中性室内摄影，没有人脸，没有水印。竖图和横图都必须完整显示，禁止裁切来填满格子。图号写在画面下方，不压在照片上。文件名比图号小一号。选中只加 #6366F1 描边，不把其他图挤开。

顶栏高 56，底 #131A29，底边 #27354D。所有画板相同。左侧方标加「灵感空间」和小号 PRO。导航四项：空间创作、素材库、剪辑、设置。空间创作为当前项。右侧依次是：适老、主题「暗黑」（菜单里还有明朗、护眼）、绿色状态「在线」、圆形用户头像。不要在顶栏放「导出档案」。

画板一，对话页，右抽屉关闭。顶栏下三列。

左列宽 300，标题「对话历史」。五条会话，当前条左边 2px #6366F1。底部「新对话」。列顶有收起图标。

中列从上到下：

1. 消息区较矮，只露出一条用户消息和一张小结果图。用户消息里有青色芯片「图1」。右上角小字「向上滚动查看更早记录」。
2. 看图区高度固定，约占中列七成，底色 #0A0E17。这一屏是两张图，一竖一横，证明拼法：左边 9:16 的玄关窄列，右边 16:9 的客厅占满剩余宽度，两张顶边对齐，都完整可见，不要变成同样大小的两张竖图。图下方分别是「图1」「图2」和文件名。图1 有靛蓝描边。每张图右下有铅笔和删除两个线框图标。看图区右上是文字按钮「收缩」。不要左右箭头，不要轮播，不要在看图区里再放一个大号添加卡片。
3. 底条贴在看图区下面。一排约 72px 的小图，下面标图1、图2，末尾是虚线「添加」。底条是索引，不是第二块大图。
4. 输入区固定在最底，底 #131A29。两行：标签「配方句」，内容是「将」加青色芯片「图1」加「改为原木侘寂风。微水泥、朴素柜面、自然漫射。保持原有空间结构。」标签「补充句」，占位「例如沙发再深一点」。左侧分段：对话、生图、生视频、生音乐，生图选中。旁边是模型名和画幅 16:9。还有文字按钮「按这些图给建议」、次按钮「预览请求」、实心主按钮「生成」。一个区域只有这一个实心主按钮。

右缘只有一条竖向标签「精准编辑」，表示抽屉关闭。

画板二，同一页，看图区换成三张。其中一张明显更竖：它单独占左列；右边上下叠两张较横的室内图。三张都完整。底条有图1、图2、图3 和添加。其余与画板一相同。不要左右箭头。

画板三，收缩状态。看图区收起，消息区变高，能看到更多对话。底条仍在输入框上方，小图和图号都在。没有大图。右抽屉仍关闭。

画板四，右抽屉打开，宽 380。标题「精准编辑」。只有三项：风格、超分、去水印。风格选中。下面六个风格卡片，「日式侘寂」选中，卡片里有两行可编辑描述。抽屉底部一行：「已写入配方句，发送前可以改」。抽屉里不要画布，不要替换、留白、去除、扩图、增加、安装。中列仍是画板一的一竖一横。

画板五，编辑层，铺满顶栏以下的窗口。顶栏仍在。没有对话历史，没有其他参考图，没有底条。左边窄栏两个分段：「自定义」选中，「预定」。自定义下五个工具：裁剪、马赛克、框、箭头、文字。中间是正在编辑的那张 16:9 客厅大图，完整显示，图上有一个红色矩形和一个红色箭头。右边是这一工具的短说明，不要第二块画布。底部一行只读句子：「按图1上的红框和红箭头调整。」右侧次按钮「仍用原图」，实心主按钮「使用编辑后的图片」。

画板六，仍是编辑层。「预定」选中，其下六项：替换、增加、安装、留白、去除、扩图。替换选中。中间同一张客厅图上有一块白色矩形，白底里放一把沙发的立体预览，沙发不要带黑色背景板。右边参数只有：家具名称、左右角度、上下角度。底部只读句子：「在图1的框选区域，把该物体替换为亚麻沙发。朝向与家具参考图一致，左右 36 度，上下 0 度。框外画面保持原图像素。」次按钮「放弃」，实心主按钮「使用这套操作」。

画板七，仍是编辑层。预定里的换色可以不单独占一项；若这一屏要表现换色，就在预定下增加「换色」为选中。中间大图上两个编号多边形，半透明填色，角上有点。右边列表两行：「区域1 顶部墙面」加色块 #F4F0E6，「区域2 家具」加色块 #8C6A4A。上面有方案「原木暖灰」和按钮「识别」。底部只读句子写明区域和色号。主按钮仍是「使用这套操作」。

所有按钮用本提示词里的中文，不要改名。不要把看图区画成随图片向下无限长的瀑布流。不要因为选中而把某一张放大、其余缩小。
