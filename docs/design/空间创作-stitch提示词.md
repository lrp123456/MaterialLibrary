# 空间创作 Stitch 提示词

把下面分隔线之内的正文整段交给 Stitch。生成暗色默认主题的桌面端一屏，宽度 1440。用户复审通过前，不要按稿改代码。

配色必须使用下面的色值。不要改成米色、暖纸色或另一套品牌色。附件若是米色轮播，只说明「多张大图横排」这一个结构，颜色以本提示词为准。

---

设计桌面 Web 应用里的一个工作区，名称是「空间创作」。它是室内设计素材库的 AI 创作页。语言是简体中文。字体：界面用 Plus Jakarta Sans，中文回退苹方；编号和图号用 JetBrains Mono。圆角 12 到 16。1px 实线边框。不要大阴影，不要玻璃拟态，不要渐变背景。

这是暗色主题，色值固定：

- 页面底 #0A0E17
- 栏和抽屉 #131A29
- 卡片 #182236
- 悬停 #212E47
- 输入槽 #0D121D
- 边框 #27354D
- 主文字 #F8FAFC
- 次文字 #94A3B8
- 弱文字 #64748B
- 主按钮和选中 #6366F1，悬停 #4F46E5，按钮文字 #FFFFFF
- 图号芯片 #06B6D4，芯片底用该色 15% 透明
- 成功 #10B981
- 危险 #F43F5E
- 警告 #F59E0B

页面上方有一条已存在的顶栏，高 56，底色 #131A29，底边 #27354D。四个文字导航：素材库、空间创作、媒体剪辑、系统设置。空间创作是当前项，用 #6366F1。不要重新设计顶栏的信息架构，只把它画出来作为上下文。

顶栏下面是工作区，占满剩余高度，三列。

左列宽 320，底 #131A29，右边框 #27354D。标题「对话历史」。列表是过去的会话，一项标题加时间。当前项底 #212E47、左边 2px #6366F1。底部有「新对话」。列顶有收起图标。

中列是唯一的主工作区，从左到右分为三截，纵向排列：

1. 消息区，占中列剩余高度，可向上滚动。里面有一条用户消息和一条助手图片结果。用户消息里有青色芯片「图1」。助手结果是一张室内图，缩略显示，不要占满屏幕。
2. 看图区，默认高度约占中列 70%。底 #0A0E17。这一区一次展示两张同样大的完整照片，横排，间距 16，每张都完整可见，不要左右只露出一条边，也不要中间一张特别大。照片是室内客厅和室内细节。每张卡片底 #182236，边 #27354D。卡片顶部用等宽字体写「图1」，下面一行小字是文件名。当前选中的卡片边框 #6366F1。卡片右下有两个图标按钮：铅笔、删除。看图区左上有左右箭头，用于在多于三张时转动。右上有「收缩」。看图区右侧尽头有一个虚线卡片「添加」，加号。
3. 输入区固定在中列底部，底 #131A29，上边框 #27354D。分两行输入：第一行标签「配方句」，第二行标签「补充句」。配方句里已经有文字，并包含一个青色芯片「图1」。补充句是空的，占位「补充你的要求，例如沙发再深一点」。右侧有「预览请求」次按钮和「生成」主按钮。生成按钮 #6366F1。

右列默认不要画开。在这一稿的右缘只放一个竖向图标按钮「精准编辑」，表示抽屉关闭。

请在同一文件里再给六个独立画板，尺寸同样是 1440 宽，顶栏保持不变。

画板二，右抽屉打开。抽屉宽 400，底 #131A29，左边框 #27354D。标题「精准编辑」。两组：全局、预定。全局里三项：风格、超分、去水印。风格是选中态。下面是风格网格，一项选中，边框 #6366F1。选中项下方有一段可编辑的风格描述。抽屉底部一行状态：「已写入配方句，发送前可以改」。中列看图区仍是两张同样大的图。

画板三，自定义编辑。看图区只聚焦被编辑的那一张大图，图上有一个红色矩形和一个红色箭头。图上方工具条：裁剪、马赛克、框、箭头、文字、退出。退出用次按钮。不要在右侧再放一块画布。

画板四，预定替换。同一张大图上有一个白色矩形区域，区域里放一把沙发的立体预览。右抽屉是参数：家具名称、左右角度、上下角度。抽屉顶部一句提示：「在图上框出要替换的位置，再旋转家具」。底部两个按钮：「使用这套操作」「放弃」。

画板五，换色。大图上有两个编号多边形，半透明填色，角上有可拖动的点。右抽屉列表两行：「区域1 顶部墙面」加色块，「区域2 家具」加色块。上面有方案选择、几个单色、一个色号输入框。另有按钮「识别」。

画板六，请求。从中列右侧滑出一层面板，宽 480，盖住右抽屉位置。四段等宽字体内容：原文、编译后的正文、图列表、curl。图列表一行写「图1  来源：看图区  路径：/api/assets/...」。key 和 token 的位置显示 `***`。面板标题「本次请求」。

画板七，看图区收缩。看图区高度约 88，只剩一排 64 见方的小图，每张下面有「图1」「图2」。消息区因此变高。输入区仍固定在底部。

所有画板的照片内容使用中性的室内设计摄影，不要出现人物脸、不要出现水印、不要出现英文营销口号。按钮文案使用本提示词里的中文，不要自行改名。

## 复审时看什么

- 两张图同样大，不是中间一张巨大、两侧一条缝。
- 颜色是 #0A0E17 / #131A29 / #6366F1 / #06B6D4 这一套。
- 配方句和补充句分成两行。
- 右抽屉里没有第二块大画布。
- 收缩之后消息区变高，输入框还在底部。
