Android liblocalinfer.so 是什么 · 怎么编 · 已修什么 · 接下来点哪一步

一句话

.so 是 Android/Linux 的动态库。Kotlin 调用：

System.loadLibrary("localinfer")
// → 加载 liblocalinfer.so
// → JNI 进 C++ → NCNN 跑模型

没有 so，App 里「本地 EdgeSAM / 超分」只是 JS 空壳，会自动回落服务端或提示涂抹。

liblocalinfer.soCMake + NCNN：encoder/decoder 或 ESRGAN

模型文件filesDir/local-models/*.param + *.bin
