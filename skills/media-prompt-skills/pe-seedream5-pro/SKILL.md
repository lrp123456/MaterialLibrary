# Seedream 5.0 pro 提示词优化

模型 ID：`doubao-seedream-5-0-pro-260628`。三大独占能力：**交互编辑**、**图层拆分**、**原生多语种**（俄/阿/菲/泰/土/韩/马来/西/葡/印尼/法/德/越/日 等 14 种）。

> 通用写作规则与 lite 完全一致（主体+行为+环境、双引号文字、禁模糊代词、参考图两段式、图一图二绑定、≤300 汉字/600 英文单词、简洁优于堆词）。本 skill 只列 pro 独占内容。

## 一、交互编辑（pro 独有）

输入要素 = **待编辑图片** + **prompt（定位信息 + 编辑指令）**。两种定位形式：

**形式 1：任意标记 + 自然语言定位**（手绘草图、涂鸦、圈选）

```text
根据手绘草图对图像进行编辑。在左下角标记区域添加一叠真实的杂志或艺术画册，并在右侧标记区域添加一个带杯碟的陶瓷杯咖啡。移除所有草图线条。保持构图不变。让新添加的物体自然融入原有场景中。
```

**形式 2：坐标精准定位**（归一化坐标，范围 **0-999**，左上角 0,0、右下角 999,999）

- 点选：`<point>x y</point>`（指定点，模型判断影响范围）
- 框选：`<bbox>x1 y1 x2 y2</bbox>`（左上角＋右下角，精确控制区域）
- 换算：`x = round(x_px / width * 1000)`，`y = round(y_px / height * 1000)`（width/height 为图片在画布中的展示宽高）

```text
把图 1 <point>520 460</point> 位置换成皇冠
把图 1 <bbox>120 180 640 760</bbox> 区域替换成花园
将图 1 <bbox>179 283 796 986</bbox> 的主体放到图 2 <bbox>118 331 933 871</bbox> 位置，将图 2 <point>50 50</point> 位置换成皇冠
```

**多主体场景的两条纪律**：

- 框选区域内存在多个主体时，**在 prompt 里点名要编辑的对象**（「左侧的人」「戴帽子的猫」「前景的花」）：`把图 1 <bbox>120 180 640 760</bbox> 区域内的左侧人物换成机器人`
- 要保持不变的对象，**一并框选并声明**：`把图 1 <bbox>120 180 640 760</bbox> 区域替换成花园，图 1 <bbox>700 120 920 360</bbox> 区域保持不变`

## 二、图层拆分（pro 独有）

开启方式：`layer_decomposition: true`（此时 `image` 必填且**仅支持 1 张**待拆分图，`prompt` 可选）。输出 = **1 张底图 + 最多 16 个带透明通道的 PNG 图层**，并返回图层坐标、层级顺序与内容说明。

prompt 三种写法：

| 目标 | 写法 |
| --- | --- |
| 自动拆主要元素 | 不传 `prompt`，模型自动拆分主体/文字/背景/装饰元素 |
| 指定拆分对象 | 自然语言描述，如「拆出人物、标题文字和右下角装饰图标」，可配合涂鸦/圈选辅助 |
| 精准指定区域 | 用 `<bbox>` 归一化坐标标签指定待拆元素位置 |

- 尺寸：拆分场景 `size` 默认 `auto`，可选 `1K` / `1.5K` / `2K` / `auto`（底图分辨率与 `size` 一致且保持原比例；各图层分辨率与 `size` 接近并保持各自原比例）。
- 拆分场景输入图：png/jpeg，总像素 [262144, 3600 万]，单张 ≤30MB，仅单张。
- 计费/限流：每次请求按最多 17 张（1 底图 + 16 图层）预扣 IPM，按实际数量返还。

## 三、输出规格

- 分辨率档位：`1K`、`1.5K`、`2K`（**1.5K 与 1K 同价且效果更优，优先选 1.5K**）。
- 常用映射：1K → 1:1 `1024x1024`、16:9 `1424x800`、9:16 `800x1424`；1.5K → 1:1 `1536x1536`、16:9 `2048x1152`；2K → 1:1 `2048x2048`、16:9 `2816x1584`、21:9 `3136x1344`。
- 像素值方式：总像素范围 [921600, 4624220]（约 1280x720 ~ 2048x2048x1.1025），比例 [1/16, 16]。
- 输出格式：png、jpeg；`response_format`：url / b64_json；`watermark`：false / true（true 时右下角加「AI生成」）。
- **透明通道**：`background: "transparent"` 出透明底图——仅图生图场景、只支持输入 1 张带透明通道的图片，输出默认 png（配 jpeg 会报错，传 jpeg 输入也会报错）。
- 提示词优化模式：`optimize_prompt_options.mode` = `standard`（默认，质量更优）或 `fast`（更快）。
- 参考图：最多 **10 张**（比 lite 少）；单张 ≤30MB。
- **不支持**：文生组图 / 单/多图生组图、流式输出、联网搜索。生成图 URL 仅保留 24 小时。

## 四、prompt 写法建议（pro 特有场景）

- **高信息密度信息图/海报**：明确版面结构（网格排版、分栏、阅读顺序、标题层级），把要出现的文字逐条用双引号给出，并声明「只使用提供的文字，不新增数据/图表」。
- **多语种文字渲染**：注明目标语言（中文/英文/日语…），文字放双引号，复杂排版保持文字风格统一。
- **局部替换/属性重构**：明确「改什么 + 保留什么」——`请依据图 1 的材质和图 2 的色卡，修改图 3 中的沙发`、`把菜单翻译成中文`。
- 空间关系交给框选/坐标表达，比长篇文字更准。

## 五、输出前自检

- 交互编辑任务：定位信息（标记或 `<point>/<bbox>` 归一化坐标 0-999）写了吗？多主体是否点名？要保持的对象是否已声明？
- 图层拆分任务：`layer_decomposition: true` + 单张输入 + `size` 用档位/auto？
- 透明通道任务：是否单张带透明通道输入且输出 png？
- 是否误加了 pro 不支持的组图/流式/联网诉求？
