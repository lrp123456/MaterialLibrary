# Agnes Image 2.5 Flash 提示词优化

模型：`agnes-image-2.5-flash`，端点 `POST /v1/images/generations`。当前所有分辨率档位与参考图均 ¥0。

**免费档红线：输入参考图严格 ≤3 张**（刊例价前 3 张免费，第 4 张起 ¥0.02/张）。用户要给更多参考图时，提示先合并/取舍到 3 张以内。

## 一、官方提示词结构（按模式）

### 1）文生图
```text
[主体] + [场景/环境] + [风格] + [光照] + [构图] + [质量要求]
```
示例：`日出时分薄雾峡谷上方的发光浮空城市，电影级写实风格，广角构图，丰富的建筑细节，柔和的金色光线，高视觉密度`

### 2）图生图
```text
[基于 @图片1 的改变要求] + [新风格/场景] + [需要添加或移除的元素] + [需要保留 @图片1 的哪些元素]
```
示例：`将 @图片1 中的白天街道场景改为电影级赛博朋克夜景，添加霓虹招牌和湿滑路面倒影，同时保留 @图片1 的原始街道布局、相机角度和主要建筑形状。`

> **红线：严禁写成模糊代词“参考图”！必须明确指明 @图片1**（否则前端无法渲染行内缩略图胶囊，多图时模型无法分辨）。"需要保留的元素"是必写项。

### 3）多图合成
```text
[@图片1 角色] + [@图片2 角色] + [目标场景] + [图像之间的关系] + [风格/光照/构图]
```
**必须说明每张参考图的角色（严格用 @图片1、@图片2 指代，严禁写“图一/第一张图”）。** 
示例：`将 @图片1 作为主要角色，@图片2 作为产品参考，生成一张电影级活动海报，保留 @图片1 的角色身份和 @图片2 的产品外形，使用自然光照和干净的商业构图。`

### 4）高信息密度图
清晰描述视觉层次：**主要主体 + 背景环境 + 重要次要细节 + 风格/光照/构图约束**。避免堆砌无关细节导致画面杂乱。

## 二、参数速查

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| model | 是 | `agnes-image-2.5-flash` |
| prompt | 是 | 生成/编辑文本指令（正文中必须用 `@图片1`、`@图片2` 锚定素材） |
| size | 是 | 档位 `1K`/`2K`/`3K`/`4K`（推荐）；`1920x1080` 类精确尺寸会被标准化 |
| ratio | 否 | `1:1`（默认）`3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` |
| extra_body.image | 图生图必填 | 输入图数组：**必须是真实公共 URL 或 Data URI Base64**，由系统在提交时根据 `@图片N` 自动解析填充；**严禁直接将占位符字面量 `"@图片1"` 当作 URL 填入数组**；**≤3 张（免费档）** |
| extra_body.response_format | 否 | `url` 或 `b64_json`；**禁止放请求体顶层** |
| return_base64 | 否 | 仅文生图 Base64 输出用 |

常用输出尺寸：2K+16:9 = 2624x1472；1K+1:1 = 1024x1024；4K+16:9 = 5248x2944。要 1920x1080 显示器素材 → 请求 `2K`+`16:9` 再下游缩放。

## 三、常见错误（规避）

- 提示词写“参考图”、“第一张图” → 必须写 `@图片1`、`@图片2`。
- `extra_body.image` 填入 `["@图片1"]` → 错误！必须填真实 URL 或由系统运行时映射，占位符仅留在 prompt 文本中。
- `response_format` 放顶层 → 必须放 `extra_body`。
- 图生图传 `tags: ["img2img"]` → 不需要。
- 图生图缺 `extra_body.image` → 必填（底层提交时）。
- 输入图 URL 需登录/私有 → 改 Data URI Base64。

## 四、输出前自检

- 素材指代严格为 `@图片1`、`@图片2`（严禁使用“参考图”、“原图”、“图一”等模糊代词）？
- 参考图 ≤3 张？
- 提示词结构匹配任务模式（文生图 / 图生图 / 多图合成 / 高信息密度）？
- size 用档位 + ratio 组合（没写像素值）？
- 多图合成是否写明每张图的角色？图生图是否写了"需要保留的元素"？
- `response_format` 是否放在 `extra_body` 内？

## 五、交付模板

见 media-prompt-gateway 的输出契约。
- **纯文本模式（如 App 优化提示词回填）**：直接输出包含 `@图片1` 的最终提示词文本；
- **JSON 参数推荐模式**：输出完整请求片段，其中 `prompt` 包含 `@图片1`，`extra_body.image` 标明 `["<由@图片1解析得到的真实图片URL或Base64>"]`。
