# Seedream 5.0 lite 提示词优化

模型 ID：`doubao-seedream-5-0-260128`（别名 `doubao-seedream-5-0-lite-260128`）。能力覆盖文生图、文生组图、单/多图生图、单/多图生组图、流式输出、联网搜索。

## 一、通用写作规则

1. **画面描述结构**：`主体 + 行为 + 环境`，用**简洁连贯的自然语言**写成句子；有美学要求再补 `风格 / 色彩 / 光影 / 构图`。
2. **写明用途和类型**：logo、海报、绘本、信息图等靠前写。
3. **风格**：用精准风格词，或提供参考图。
4. **图中文字必须放双引号**：`生成一张海报，标题为 "Doubao Seedream 5.0"`。
5. **编辑类**：简洁明确指令，**禁止模糊代词**（✗「让它穿上粉色衣服」）；需保持不变处写「保持…不变」；复杂区域用箭头/线框/涂鸦标明位置。
6. **长度**：prompt 建议 **≤300 个汉字或 600 个英文单词**——超了模型会忽略细节、漏元素。
7. 模型理解力强、画面不泛白，**简洁精确优于堆砌华丽词汇**。

## 二、按模式写

**文生图**

```text
一个凌乱的办公桌桌面。桌面上有一台开着的笔记本电脑，屏幕显示绿色代码；旁边一个马克杯，杯上写着"Developer"，杯口冒出热气；一本摊开的书，页面是维恩图…阳光从右侧照射，在桌上形成光影。
```

**图像编辑（增/删/替换/修改）**

```text
增加：给图中女生增加相同款式的银色耳线和项链。
删除：去掉女生的帽子。
替换：把最大的面包人换成牛角包形象，保持动作和表情不变。
修改：让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿。
涂鸦控制：将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局。
```

**参考图生图（两段式，缺一不可）**

```text
[指明参考对象：要保留的元素] + [描述生成画面]
参考图标的线性简约风格，设计9个不同场景下的应用 icon：音乐、天气、日历…保持一致的配色。
```

**多图输入**：用 `图一`、`图二` 明确绑定——`将图一的主体替换为图二的主体`、`让图一人物穿上图二的服装`、`参考图二的风格，对图一进行风格转换`。

**组图输出**（5.0 lite 支持；**5.0 pro 不支持**）

- 触发：写「一套 / 一系列 / 组图」或明确数量；参数需 `sequential_image_generation: "auto"` + `sequential_image_generation_options.max_images`。
- 组图 prompt 模板：`生成一组<风格>的 N 张<用途>：场景1为…；场景2为…；场景3为…`（每个场景单独写清主体、动作、光影、构图）。

```text
生成一组电影级科幻写实风的4张影视分镜：场景1为宇航员在空间站维修飞船…；场景2为突然遇到陨石带袭击…；场景3为宇航员紧急躲避…；场景4为受伤后惊险逃回飞船…
```

**草图/设计图生成**：图中有文字时注明「遵循图中文字内容进行生成」。

## 三、尺寸与参数

- 分辨率档位：`2K`、`3K`、`4K`（不支持 1K/1.5K）。
- 常用档位映射：2K → 1:1 `2048x2048`、16:9 `2848x1600`、9:16 `1600x2848`、3:2 `2496x1664`、21:9 `3136x1344`；4K → 1:1 `4096x4096`、16:9 `5504x3040`。
- 也可直接写像素值 `宽x高`（总像素范围 [3686400, 16777216]），**两种方式不可混用**。
- 其他参数：`output_format`（png / jpeg）、`response_format`（url / b64_json）、`watermark`（false / true）。
- 参考图：最多 **14 张**；**参考图数量 + 最终生成图片数量 ≤ 15 张**。
- 输入图约束：格式 jpeg/png/webp/bmp/tiff/gif/heic/heif；总像素 [196, 3600 万]；宽高 >14px；比例 [1/16, 16]；单张 ≤30MB。
- 生成图 URL 仅保留 **24 小时**，及时保存。

## 四、输出前自检

- 主体+行为+环境成句？没用词堆？
- 图中文字已加双引号？编辑指令无模糊代词？参考图任务两段齐全？多图已用「图一/图二」编号？
- 字数是否 ≤300 汉字？保持项是否显式声明？
- 组图任务是否写了场景编号与数量？（pro 用户请改走 pe-seedream5-pro 并去掉组图诉求）

## 五、交付模板

见 media-prompt-gateway 输出契约。【推荐参数】给出 model（`doubao-seedream-5-0-260128`）、`size`（2K/3K/4K 或像素值）、`output_format`、`watermark`、组图时的 `sequential_image_generation` 与 `max_images`、参考图清单与数量（≤14，且参考图＋出图 ≤15）。
