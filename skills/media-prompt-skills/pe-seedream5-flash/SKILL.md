# Seedream 5.0 Flash 提示词优化与工程指南

Seedream 5.0 Flash（`doubao-seedream-5-0-flash-260915`）是系统当前**主动生图与人像创作的官方默认模型**，具备极速出图、高光影质感与真实空间透视表现力。

## 适用场景
- 室内设计实景效果图渲染
- 多图参考风格迁移与材质融合
- 商业空间、硬装材质细节还原
- 空间人像写真与漫游打卡

## 参数规范与推荐值

```yaml
model: doubao-seedream-5-0-flash-260915
size: 1024x1024  # 推荐尺寸：1024x1024 (正方), 1080x1920 (9:16 竖屏), 1920x1080 (16:9 横屏), 1536x2048 (3:4 效果图)
count: 1         # 单次生成数量，建议 1-2
prompt_strength: 0.75 # 提示词遵循度 (0.1 - 1.0)
seed: -1         # 随机种子，-1 为随机
```

## 素材指代与多图参考规范
- 多图输入严格使用 `@图片1`、`@图片2` ... 语法进行指代。
- 参考规则：
  - 风格参考：明确说明参考 `@图片1` 的色温、光影氛围或材质纹理。
  - 布局参考：明确说明参考 `@图片2` 的空间布局与机位视角。
  - 主体融合：如「保持 `@图片1` 的沙发造型与皮革质感，放置在现代轻奢客厅的中央」。

## 四段式优化结构

1. **① 素材绑定**：
   明确声明各参考图的映射职责。
   例如：`参考图映射：空间硬装参考@图片1，主沙发与茶几单品参考@图片2。`

2. **② 一句话概述**：
   `【空间类型】+【设计风格】+【核心视觉焦点】+【主光照环境】`。
   例如：`现代极简侘寂风宽敞客厅实景效果图，落地窗引入清晨柔和漫射日光。`

3. **③ 具体空间与材质细节**：
   - 空间定位：墙面微水泥质感、大理石地砖反光细节、局部艺术吊顶。
   - 家具单品：棉麻布艺主沙发、原木肌理茶几、金属极简落地灯。
   - 绿植装饰：角落一株琴叶榕，叶片翠绿带自然微光。

4. **④ 镜头语言与结尾质感**：
   广角透视机位，水平视平线，无畸变，景深自然，色彩真实饱满，无过度饱和，呈现自然逼真的室内摄影级质感。
