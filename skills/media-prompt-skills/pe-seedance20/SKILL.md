# Seedance 2.0 提示词优化

定位：原生音视频联合生成、全模态参考（视频/图片/音频）、中文自然语言。**关键约束：2.0 不响应精确时间戳，只响应镜头序号**——所有"秒级时间窗"必须改写为分镜序号+事件顺序。

## 一、基础公式（按任务选）

**1）全模态参考**（从素材提取元素生成全新视频）

```text
图片参考：参考<图片N>中的<主体N>，生成...
视频参考：参考<视频N>中的<动作/运镜/风格/音效>，生成...
音频参考：参考<音频N>中的音色，生成...
```

**2）编辑视频**（原视频局部/全局修改；**未提及的部分默认保持不变**）

```text
增加元素：<元素特征> + <出现时机> + <出现位置>
修改元素：严格编辑<视频N>，将其中的<原特征>修改为<新特征>
删除元素：点明要删除的元素，并强调保持不变的元素
```

**3）延长视频**（延续原视频，风格/主体/叙事一致）

```text
向前/向后延长<视频N>，生成...
轨道补全：<视频1> + <过渡画面描述> + 接 <视频2> + <过渡画面描述> + 接 <视频3>
```

**4）组合任务**：`参考<图片/视频N>的[参考维度]，严格编辑<视频X>，[具体编辑内容]`

> 编辑/延长任务中**直接写 `<视频N>`，不要写"参考 `<视频N>`"**，否则会被误判为参考任务。

## 二、进阶公式（工程型指令）

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

模型内部把提示词拆成"空间层"（画面里有什么）与"时间层"（事情如何随时间变化），所以要先锁定"谁在干什么"，再交代"在哪/什么氛围"，然后"怎么拍"，最后用风格、画质、约束条件收口。

**1）定义主体**（精准引用的前提）

```text
将<图片/视频N>中的[主体核心特征]定义为<主体N>
```
- 核心特征＝**2-3 个清晰稳定的静态特征**（服饰、发型、外观、类别）。
- 示例：`将图片1中穿红色连衣裙、戴草帽的女人定义为主体1`（也可命名为「张红」）。
- 多素材同主体：`将图片1中的[...]、图片2中的[...]定义为<主体N>`。
- 多主体分别定义并使用唯一标签，后续持续用同一标签：`将视频1中的高个子男人定义为警察，将另一个矮个子男人定义为小偷`。
- 简单场景未提前定义时，每次提到主体都要写成 `<主体N>@<图片N>`（如 `张三@图片1`）。
- 用素材库 Asset ID 时仍必须用 `<图片N>` 指代，不得直接用 Asset ID。
- 描述简洁、避免语义冲突；空间关系尽量交给参考图表达。

**2）分镜时序（替代时间戳，关键规则）**

- 用 `镜头1`、`镜头2`、`镜头3` 按事件顺序（先主后次）组织，不强制每段时长。
- **官方说明：模型对精确时间（如 0-3 秒）支持不稳定，强行限制时长可能导致生成异常** → 2.0 任务一律不交付秒级时间窗。
- 每个镜头按 4 项组织：①运镜或切换方式 ②主体动作与表情 ③位置/空间变化 ④音频信息。

```text
镜头 1：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。
镜头 2：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。
镜头 3：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。
```

**3）动作描述要求**

- **肢体细化 + 程度量化**：缓慢抬手、快速转头、用力蹬地、微微低头。
- 优先**低缓连续小动作**，规避狂奔、大跳、剧烈翻滚。
- **补充过渡衔接**：借着转身惯性顺势抬手、从停顿状态自然过渡到举手。
- **情绪具象外化**（禁止"很悲伤"这类抽象词）：
  - 悲伤：低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角
  - 喜悦：嘴角抑制不住地上扬、脚步轻快、忍不住原地转个圈
  - 紧张：频繁看手表、手指敲桌、呼吸急促、眼神闪躲
  - 愤怒：双拳紧握、下颌线紧绷、胸口剧烈起伏
  - 释然：长长舒一口气、紧绷的肩膀放松、抬头望向远方

**4）运镜写法**：直接用标准术语（中景、特写、全景、缓慢推镜、平稳横移、固定镜头）。**一个镜头只指定 1 种运镜**，同时推拉摇移会增加不稳定。

**5）画质 / 风格 / 约束词**

- 画质：高清，细节丰富，电影质感，色彩自然，光影柔和。
- 风格：赛博朋克冷蓝紫色调、复古胶片、日系清新。
- 约束词（写在末尾收口）：`保持无字幕`、`避免生成任何文字或字幕`、`不要生成Logo`、`不要生成水印`。

## 三、语言与符号规范

- 台词语言统一，避免中英混用（专有名词除外）。

| 信息类型 | 符号 | 示例 |
| --- | --- | --- |
| 音乐 | （） | （背景中播放着快节奏的摇滚乐） |
| 音效 | <> | <远处传来狗叫声> |
| 台词 | {} | {你好，世界}；小语种需标注语种：用日语说道{こんにちは} |
| 字幕 | 【】 | 【第一章：启程】 |

## 四、素材配置策略

四种功能角色：角色锚定 / 场景定调 / 运镜参考 / 节奏氛围。推荐配置（**总计 4-5 个素材**）：角色图 1-2 张（面部特写＋全身）＋场景图 1 张＋运镜视频 1 段＋音频 1 段。**不建议用满上限**（特征优先级混乱、风格冲突、主体识别模糊）；越需要精准参考的素材放越前面。

## 五、常见问题速查

| 问题 | 解法 |
| --- | --- |
| 人物 ID 漂移/换脸 | 人脸特写大头照＋全身照双素材；写明"<主体1>的面部特征参考图片1（大头照），妆造参考图片2"；**不要用多视图/三视图**；重要素材前置 |
| 生成多余字幕 | 约束词"保持无字幕"；参考素材先去文字；横屏比竖屏不易出字幕 |
| Logo/水印 | 约束词"不要生成水印""不要生成Logo" |
| 风格漂移（动漫→写实） | 显式风格约束词（"2D日漫风格""3D国风漫画"）；参考图先转目标风格 |
| 延长衔接跳变 | 后期修帧：前段末尾删 6 帧、后段开头删 1 帧；续写以切镜时刻结尾，下一段从新场景起始 |
| 延长画质劣化 | 先转白模再续写（"将视频转为白色 3D 模型…纯白背景，结构稳定、运动流畅"）；控制续写次数 |
| 双胞胎/人物重复 | 主体定义清晰（人名＋对应参考图）；末尾加全局约束句；单人独立照片；精简提示词 |
| 参考人物 >4 人 | 分组生成图片（每组 ≤4 人）再图生视频 |
| 特效不符合预期 | 用参考视频定义特效（"数字出场方式参考视频1"），不要纯文字描述复杂特效 |
| 片尾咔哒噪音 | 剪辑软件做音频淡出 |
| 多音字发音错误 | 替换为同音常用字（"螭龙山"→"吃龙山"） |
| 音色参考不准 | 补细致音色描述（"使用@音频1低厚温润带细碎颗粒感中年男声的音色说"），台词风格贴近参考音频 |

## 六、文字生成与延长策略

- 广告语模板：`「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」`。
- 字幕模板：`画面底部出现字幕，字幕内容为"……"，字幕需与音频节奏完全同步`；优先常用字，避免生僻字与特殊符号。
- **视频延长**适合单一场景长镜头文戏（长对话、情绪递进、单一路径移动，一镜到底）；**分段拼接**适合剧情转折与复杂快速武戏。实际常结合使用。

## 七、输出前自检

- 没有出现秒级时间戳（已全部转成分镜序号）？
- 主体已用「将<素材N>中的[特征]定义为<主体N>」定义？后续指代标签唯一且一致？
- 多主体是否逐一列清？未定义主体时是否写成 `<主体N>@<图片N>`？
- 约束词是否置于末尾收口（2.0 无负向提示词通道）？
- 素材是否控制在 4-5 个、重要素材前置？一个镜头一种运镜？

## 八、交付模板

见 media-prompt-gateway 输出契约。【推荐参数】给出 `model`、素材清单与顺序、画幅、时长（按镜头数估算：单镜头 5s；2-3 镜头 10s）、语言（中文）。
