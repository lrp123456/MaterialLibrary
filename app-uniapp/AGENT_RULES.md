# Material Viewer Shell (App 移动端) Agent 开发规范与交互原则

## 1. 核心定位与职责边界
- **核心定位**：服务于现场勘查、移动选样、快速灵感对话与轻量分享的原生/UniApp 客户端。
- **与服务端契约保持同步**：
  - 核心分类结构、打标系统主色调板与 AI 工作台模型列表必须与服务端 `/api/viewer/dict/menu-tree` 及 `/api/viewer/studio/schema` 保持同步；
  - 严禁 App 端脱离服务端私自修改分类名称或色彩值。

---

## 2. 关键页面交互规范

### 2.1 素材浏览页 (`pages/browse/browse.vue`)
- **顶栏一级分类下拉 (`media-type-dropdown-trigger`)**：
  - 展示当前主分类图标与名称，点击展开选择框；
  - 选项来源于统一菜单树的一级分类。
- **次级与多维过滤条 (`filter-bar-container`)**：
  - 采用水平横滑滚动条 (`scroll-view scroll-x`)；
  - 快捷胶囊展开下拉面板进行多选过滤；
  - 颜色基调筛选必须与服务端 12 色标准板一致。

### 2.2 AI 创作对话页 (`pages/chat/chat.vue`)
- **顶栏模型统一选择器 (`model-badge`)**：
  - 居中醒目展示当前推理模型；
  - 点击弹出原生 `picker` 选择器，选项从 `studioSchema.models` 读取；
  - 切换模型时自动切换底层推理逻辑与支持的模式。
- **图文混排芯片托盘 (`chip-scroll`)**：
  - 用户在输入框左侧点击 `@` 触发选材弹窗；
  - 选中的素材以不可分割芯片展示在输入框上方（包含缩略图、名称、删除键）；
  - 发送时结构化解析芯片与纯文本。
- **固定高优专属按键：【✨ 优化提示词】**：
  - 固定位于输入栏上方的快捷操作条右侧，采用明亮醒目的暖金色渐变与圆角药丸徽标；
  - 点击时调用 `optimizePromptApi`，实现由服务端专属 Skill 扩写提示词并自动回填输入框。
- **动态快捷参数胶囊 (`quick-pills`)**：
  - 画幅比例（16:9 / 9:16 / 1:1）、画质等级（2K / 4K）等胶囊动态读取服务端 Schema，点击通过原生 `picker` 快速切换。

---

## 3. App Agent 开发红线
1. 严禁篡改 `ViewerApi.js` 的统一鉴权与 401 拦截机制；
2. 保持对弱网、离线缓存的良好兼容，Schema 请求失败时必须回退到安全兜底默认值；
3. 任何网络变更与接口扩充必须在 `ViewerApi.js` 中声明统一导出函数。
